# Changelog

## 0.4.0

- The status follows the chat you have open in the Claude app.
- The installer downloads from this repository's releases. Releases are built by a GitHub workflow.
- Session stats (model, branch, context, task list step) on the status and in Clawd's lines.

## 0.3.0

- Claude Code desktop app presence through a separate companion process, with Clawd the pet.
- One-line installer with autostart and optional VS Code extension.
- File type icons for the VS Code status.

## 0.0.2

- Shows the Claude Code session name in the VS Code status.

## 0.0.1

- First release: VS Code file and workspace status, Claude Code tab detection.
